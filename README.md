# The Asif Talks (@TheAsifTalks)

> **Unfiltered Dialogues with Leaders, Bureaucrats & Changemakers.**  
> Official web platform for *The Asif Talks*, hosted by **Syed Asif**.

---

## 🎙️ About the Show
**The Asif Talks** is an educational, youth-centric dialogue and podcast platform bridging the gap between ambition and administration. Every episode is recorded in front of a live audience of **300+ students, engineering undergraduates, and civil service aspirants** at SSIEMS Parbhani, Maharashtra.

Produced in collaboration with:
- **DCode Developers Club (DDSC)** — Technical & Production Backbone
- **Shri Shivaji Institute of Engineering & Management Studies (SSIEMS)** — Academic & Venue Partner
- **Vertex Institute of Technology** — Campus & Mentorship Partner

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript

- **Animations:** Framer Motion
- **Build Tool:** Vite
- **Deployment:** Production-ready

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/SyedAsif7/theasiftalks.git
cd theasiftalks
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
